## GitHub Copilot specific

### Inline completions
Match the naming convention already present in the file.
Complete the current logical unit — don't jump ahead to the next function.
When suggesting imports: only suggest what's already in the project's package file.

### Agent mode (Copilot Chat)
Read the workspace structure before making changes across multiple files.
When editing: show a diff-style summary of what changed and why.
Never remove existing comments — they carry context you may not have.
