# Extending rune

Drop any .md file here to customize behavior.
No core files are modified. Your rules load on top.

## Examples

create `extensions/python.md`:
Always use async functions.
Use snake_case. Never use print() — use logging.

create `extensions/react.md`:
Use functional components only.
Always use TypeScript. Never use class components.

That's it. The AI tools pick it up automatically.
